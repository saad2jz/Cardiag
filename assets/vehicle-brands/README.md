# Vehicle brand marks

The assets in this directory come from the existing Simple Icons set and from
the Wikimedia Commons source list supplied for CarDiag. Manufacturer names and
logos remain trademarks of their respective owners and are used only to
identify the make selected by the user.

The application serves these files locally so the vehicle picker keeps working
offline and does not contact a third-party logo service.

`js/branding/vehicle-brand-logos.js` is the canonical manifest used by both the
vehicle identification picker and the generated PDF report.
